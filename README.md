# Security-controls
Documentation and practical analysis of CIS Critical Security Controls.

CIS Critical Security Controls
Overview:
This repository documents the CIS Critical Security Controls (CIS Controls), a prioritized set of cybersecurity best practices designed to help organizations improve their security posture and reduce cyber risk.
The goal of this project is to understand the purpose, importance, and practical application of security controls, with a focus on enterprise asset management, vulnerability management, security monitoring, and threat detection.
